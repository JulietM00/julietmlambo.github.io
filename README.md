# 🌐 Juliet Mlambo — Personal Portfolio Website

A clean, warm, and personal portfolio website built with pure HTML, CSS, and JavaScript. Designed to showcase my skills, projects, and background as a **Junior SQL & BI Developer**.

🔗 **Live Site:** [julietm00.github.io]((https://julietm00.github.io/julietmlambo.github.io/))

---

## 👩‍💻 About This Project

This is my personal developer portfolio — built from scratch without any frameworks or libraries. It serves as a central hub for recruiters, collaborators, and anyone curious about my work and background.

---

## ✨ Features

- **Fully responsive** — looks great on desktop and mobile
- **Smooth scroll animations** — sections fade in as you scroll
- **Warm & personal design** — custom colour palette with Lora serif and Nunito sans-serif fonts
- **Live GitHub project links** — direct links to project repositories
- **Resume download button** — links to LinkedIn profile
- **Contact section** — email, LinkedIn, and GitHub all in one place
- **No frameworks** — pure HTML, CSS, and vanilla JavaScript

---

## 🛠️ Built With

| Technology | Purpose |
|------------|---------|
| **HTML5** | Page structure and content |
| **CSS3** | Styling, animations, and responsive layout |
| **Vanilla JavaScript** | Scroll-triggered reveal animations |
| **Google Fonts** | Lora (serif) + Nunito (sans-serif) typography |
| **GitHub Pages** | Free hosting and deployment |

---

## 🎨 Design Choices

- **Colour palette** — warm creams, terracotta accents, and earthy tones for a personal, approachable feel
- **Typography** — Lora for headings (elegant, trustworthy) and Nunito for body text (friendly, readable)
- **Layout** — clean sections with generous whitespace and rounded cards
- **Animations** — subtle fade-up reveals on scroll using the Intersection Observer API

## 🚀 Getting Started

To run this locally:

```bash
# 1. Clone the repository
git clone https://github.com/JulietM00/JulietM00.github.io.git

# 2. Open in your browser
cd JulietM00.github.io
open index.html
```

No installs, no dependencies — just open and go.
